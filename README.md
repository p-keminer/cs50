## Übersicht

Dieses Repository bündelt meinen Bearbeitungsstand aus `CS50x`, `CS50P`,
`CS50 SQL`, `CS50 AI` und `CS50 Web`. Jede Aufgabe liegt in einem eigenen
Ordner; die drei Abschlussprojekte besitzen ihre jeweilige Detaildokumentation.

Versioniert werden Quellcode, aufgabenrelevante Daten, Tests und
Projektdokumentation. Zertifikate, Videos, Aufzeichnungen, persönliche Guides
und virtuelle Umgebungen gehören nicht zum Repository.

<a id="de-lokaler-einstieg"></a>

## Lokaler Einstieg

```bash
git clone https://github.com/p-keminer/cs50.git
cd cs50
```

Die Voraussetzungen unterscheiden sich je nach Aufgabe. C-Programme verwenden
typischerweise `make`, Python-Aufgaben `python` oder `pytest` und die
Django-Projekte ihr jeweiliges `manage.py`. Maßgeblich bleiben die originale
CS50-Aufgabenstellung und die Dokumente in den Projektordnern.

## Overview

This repository collects my work from `CS50x`, `CS50P`, `CS50 SQL`, `CS50 AI`,
and `CS50 Web`. Each assignment lives in its own directory; the three final
projects retain their dedicated documentation.

The repository tracks source code, assignment data, tests, and project
documentation. Certificates, videos, recordings, personal guides, and virtual
environments are intentionally excluded.

## Local Setup

use `python` or `pytest`, and the Django projects use their respective
